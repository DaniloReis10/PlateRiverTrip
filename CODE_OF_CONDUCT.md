# Código de conduta

## Nosso compromisso

Queremos manter este projeto acolhedor, respeitoso e colaborativo para todas as pessoas participantes.

## Comportamentos esperados

- Usar linguagem respeitosa e inclusiva.
- Aceitar feedback construtivo com abertura.
- Focar no que é melhor para o projeto.
- Demonstrar empatia com outras pessoas.

## Comportamentos inaceitáveis

- Comentários ofensivos, discriminatórios ou de assédio.
- Ataques pessoais ou provocações repetidas.
- Divulgação de informações privadas sem autorização.
- Qualquer conduta que torne o ambiente hostil.

## Aplicação

Mantenedores podem remover comentários, fechar discussões ou restringir participação quando este código de conduta for violado.

## Reporte

Se você observar comportamento inadequado, abra uma issue privada ou entre em contato com os mantenedores por um canal apropriado definido pelo repositório.
