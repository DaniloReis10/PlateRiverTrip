# Política de segurança

## Versões suportadas

Este é um projeto estático simples. A versão principal mantida é a branch ativa do repositório.

## Como reportar uma vulnerabilidade

Se encontrar um problema de segurança, evite abrir uma issue pública com detalhes sensíveis. Entre em contato com os mantenedores por um canal privado definido no repositório.

Inclua no reporte:

- Descrição do problema.
- Passos para reproduzir.
- Impacto esperado.
- Sugestão de correção, se houver.

## Boas práticas

- Não inclua segredos, tokens ou chaves de API no repositório.
- Use imagens e recursos de fontes confiáveis.
- Revise links externos antes de publicá-los.
